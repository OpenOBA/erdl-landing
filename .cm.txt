fix(evaluator): count total_evaluated as rules actually entered

SPEC 7.0.3 defines total_evaluated as the number of rules whose
unless/when evaluation was actually entered. The evaluator previously
derived it inconsistently: allMatched.length on the EMERGENCY_HALT
short-circuit path (undercounts a non-match evaluated before it) and
enabled.length elsewhere (overcounts rules skipped by skipRing or
catch-all inertness).

- add an explicit evaluatedCount incremented after the catch-all-inert
  skip, before unless/when evaluation
- use it on all return paths
- add two conformance vectors (non-match + EMERGENCY_HALT = 2; explicit
  match + inert catch-all = 1)
- clarify SPEC 7.0.3 total_evaluated wording (EN + CN)
